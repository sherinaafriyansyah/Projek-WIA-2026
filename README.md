PELITA (Pelayanan Informasi & Tempat Aduan)
Website layanan publik, yang dapat membantu Wilayah 3T (Tertinggal, Terdepan dan Terluar) untuk mengatasi masalah Transparansi dana pendidikan dan pemenuhan hak pendidikan yang belum merata. Mengangkat 3 Tema pada lomba yaitu, (Open Government Data) diterapkan melalui fitur grafik dana anggaran pendidikan yang mudah dipahami, (Civil Reporting & Accountability) diterapkan melalui fitur form laporan jika data tidak sesuai keadaan nyata, (Publik Service Tracking) diterapkan melalui fitur cek status laporan secara berkala agar laporan yang diajukan akan di tindaklanjuti dengan cepat dan tepat

Tech Stack yang digunakan :
1. HTML : Kerangka text website
2. CSS  : Style design halaman website
3. JavaScript : Interaktivitas Website
4. Supabase : Database & Back-End Website
5. Bootstrap : Framework yang kami gunakan

Cara Menjalankan Projek : 
1. Clone Repository
Clone repository GitHub ke komputer menggunakan Terminal pada Visual Studio Code : git clone [URL_REPOSITORY]
2. Install Live Server
3. Run Project
Buka folder project yang telah berhasil di-clone menggunakan Visual Studio Code. Cari file index.html, kemudian klik kanan dan pilih Open with Live Server
